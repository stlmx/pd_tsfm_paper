## 1. 验收门

### G0 数据可用（P0 出口）
- [ ] `docs/data_card.md` 全部字段填完。
- [ ] 每个缺陷类别至少有 **3 个独立试品或实验批次**，否则无法做分组切分和留一试品验证。不足时改为按批次分组，并在 D1 中记录。
- [ ] 确认相位参考的来源：同步工频参考通道、CSV 中的相位列，或可由数据推算。**没有相位参考，锚定接口无从做起**，见风险 R2。
- [ ] 分组切分脚本产出固定的 `splits/*.json`，按 seed 列出训练、验证、测试的试品编号，入库。

### G1 叙事方向（P1 出口）
统一设置：按试品分组切分；每类 5/10/20 个标注样本及全量；5 个 seed；主指标 macro-F1，取均值 ± 标准差。

| 结果 | 叙事 | 后续动作 |
|---|---|---|
| **A**：原始 TSFM 线性探针在 5-shot 和 10-shot 下的 macro-F1 比 MiniRocket 高出 ≥ 3 个点 | 迁移有效，相位锚定进一步提升 | 按原计划进入 P2 |
| **B**：原始 TSFM 不如或持平 MiniRocket，但加上简易相位切片（P1 末做快速试验）后反超 | 直接迁移失效，相位锚定修复了它（科学含量更高） | 进入 P2，引言突出「失效到修复」 |
| **C**：两者都不及 MiniRocket | 原方案不成立 | 停下来拍板 D3 回退方案：改用 PRPD 图谱 + 视觉预训练模型，或改写成「TSFM 在局放上的系统评测」 |

### G2 结果冻结（P3 出口）
- [ ] E1–E7 全部完成，5 个 seed，逐样本预测写入 `outputs/frozen/<date>/`，并记录文件哈希。
- [ ] 论文所有表格由脚本从冻结文件生成，不允许手抄数字。
- [ ] `experiments/runs.csv` 中每一行都有 git commit 和输出路径。

### G3 投稿前检查（P5 出口）
- [ ] 正文、摘要、图注、结论中的数字与冻结文件一致。
- [ ] 文中写明分组切分协议，包括试品编号表和少样本抽样规则。
- [ ] 基线齐全，并说明每个基线的超参来源。
- [ ] 加入数据可用性声明，说明实验室数据是否公开。
- [ ] 按 MST 模板排版；准备 cover letter，以及 3–5 位推荐审稿人。

## 4. 风险登记

| ID | 风险 | 影响 | 应对 |
|---|---|---|---|
| R1 | 每类独立试品太少（< 3） | 无法分组切分，结果被质疑泄漏 | 按实验批次分组；在文中坦白试品数，并加一个留一试品实验 |
| R2 | 数据里没有工频相位参考 | 锚定接口无法实现 | 由 PRPD 中的相位列恢复；或用信号里的工频干扰估计相位；最后的退路是改为 PRPD 序列输入 |
| R3 | TSFM 不如 MiniRocket | 主叙事不成立 | 按 G1 中的 B / C 路线处理 |
| R4 | 序列长度超过 TSFM 的上下文窗口（如 MOMENT 为 512） | 需要截断或降采样，可能丢失信息 | 改为以周期为单位的 patch，或先做脉冲提取再输入 |
| R5 | 与 PowerBrain 时间冲突 | 两篇都延误 | P2 只维持 GPU 批量跑，写作放到 12 月 |
| R6 | 引用的文献信息有误 | 审稿扣分 | 写入 bib 前逐篇核对 DOI |
